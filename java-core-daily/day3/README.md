# Day 3 – Inheritance & Polymorphism

## ✅ Topics Covered

- Inheritance: Extending a class to reuse behavior
- Method Overriding and Polymorphism
- Abstract classes and real-world modeling
- "IS-A" relationships
- Code reuse and dynamic method dispatch

## 💡 Key Learnings

- A subclass inherits methods and fields from its superclass.
- Method overriding allows child classes to change behavior.
- Abstract classes help in enforcing structure but allow partial implementations.
- Polymorphism helps in writing flexible and extendable code.

## 💼 Real-World Modeling (HR System)

- `Employee` is an abstract class
- `Developer` and `Manager` are concrete roles
- Methods like `performDuties()` behave differently depending on the actual object
